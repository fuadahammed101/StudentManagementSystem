# 🎓 Student Management System (C++)

A simple console-based Student Management System built in C++. This project allows you to **add**, **display**, **search**, **update**, and **delete** student records using basic C++ arrays and file I/O.

---

## 🚀 Features

* Add new student records
* View all student records
* Search student data by ID
* Update student information
* Delete specific or all records
* Simple CLI interface

---

## 🧑‍💻 Technologies Used

* **Language:** C++
* **Compiler:** g++ / Code::Blocks / Dev-C++

---

## 📂 Functional Overview

| Option | Description                              |
| ------ | ---------------------------------------- |
| 1      | Insert new student data                  |
| 2      | Display all stored student data          |
| 3      | Search for a student by Student ID       |
| 4      | Update an existing student's information |
| 5      | Delete specific or all student records   |
| 6      | Exit the program                         |

---

## 🛠️ How to Run

1. **Clone the Repository:**

   ```bash
   git clone https://github.com/yourusername/student-management-system.git
   ```

2. **Compile the Program:**

   ```bash
   g++ main.cpp -o StudentManagement
   ```

3. **Run the Program:**

   ```bash
   ./StudentManagement
   ```

---

## 📌 Notes

* This is a beginner-level project, ideal for practicing C++ fundamentals.
* Data is stored in memory only during program execution (not saved to file/database).
* Maximum of 20 student records supported by default (as defined in `#define size 20`).
